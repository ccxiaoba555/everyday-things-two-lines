Two lines that explain a zipper to a 10-year-old — 302 characters, one vivid analogy and an honest account of what it leaves out:

> A zipper is two rows of tiny metal teeth on your jacket taking turns holding hands, so the cold wind cannot sneak in between them.
> It maps the teeth locking one by one to seal the gap, but leaves out the slider, the little wedge that pushes them together, and that a stuck tooth can jam the whole line.

The program writes those two lines to `/output/entry.txt` for make.fun's "Everyday Things, Two Lines" bounty. It self-checks the 1–400 character gate, the exact two-line rule and the one-sentence-per-line rule before writing, then reads the file back to verify it landed byte for byte.

## Run it

```sh
python3 main.py
```
